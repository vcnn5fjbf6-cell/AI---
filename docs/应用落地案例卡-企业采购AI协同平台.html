飞书入口 + Dify Chatflow + 采购审批流 + 供应商报价 + BI日志

01 业务价值（30分）
  • 解决采购需求零散、填单复杂、审批信息不完整问题
  • 自然语言、链接、Excel 可转采购候选
  • 确认后生成正式申请，复用原采购审批流
  • 普通采购进入月度需求池，紧急采购直达报价
  • 沉淀采购、审批、报价、售后和BI数据
02 创新亮点（20分）
  • 飞书机器人承接采购入口，降低系统进入门槛
  • Dify 统一判断意图、候选生成和AI审核意见
  • 候选卡片支持分页、撤回、恢复和确认提交
  • 审批卡片支持同意、退回和单项驳回
03 技术实现（25分）
  • 架构：Vue 前端 + Spring Boot 后端 + MySQL
  • AI：Dify Chatflow 输出结构化 JSON
  • 集成：飞书登录、长连接事件、交互卡片回调
  • 流程：V1-V8 可配置审批节点与数据权限
  • 安全：消息日志、导入记录、幂等和审计追踪
04 应用效果（15分）
  • 需求人在飞书中即可发起和确认采购候选
  • 审批人可在卡片内查看明细和AI审核意见
  • 供应商报价、中标确认、递补规则线上闭环
  • 管理员可通过日志排查 Dify 和飞书链路
  • 待补充：平均填单耗时、退回率、审批耗时
05 推广价值（10分）
  • 可复制为多机房采购需求入口和审批模板
  • 可推广到维保、办公用品、低值易耗品采购
  • Dify DSL 可复用，模型和搜索工具可替换
  • 可扩展供应商知识库、预算校验和采购问答
06 团队协同（10分）
  • 参与角色：采购、审批人、供应商、平台管理员
  • 技术协同：前端、后端、飞书、Dify 和部署
  • 机制：灰度卡片、日志追踪、权限与流程复用
  • 贡献：把采购经验沉淀为标准化AI工作流
