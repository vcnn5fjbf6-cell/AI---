# v20260820.4 生产候选说明

## 发布内容

- 供应商最高权限账号升级为“供应商全量监督管理”，可跨供应商查看和导出已售订单。
- 该账号可管理全部供应商订单中的发票、送货单及供应商侧售后处理，不再仅限只读查看。
- 普通供应商仍只能管理本供应商数据；采购方收货确认、财务发票审核、采购审批、系统管理和原始报价修改权限保持隔离。
