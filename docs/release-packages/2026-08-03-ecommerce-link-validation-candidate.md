本批次包含：

- 从京东分享文案中提取可点击地址，将京东移动商品页转换为电脑端商品页。

- 历史无效链接在询价单中显示“链接无效，请联系采购人”，不再作为错误地址下发。

本批次不包含：

- 不修改历史采购数据，不自动替换历史无效链接。
- 不包含数据库结构或生产环境变量变更。
- 不包含与商品链接校验无关的采购、维保或审批流程调整。
