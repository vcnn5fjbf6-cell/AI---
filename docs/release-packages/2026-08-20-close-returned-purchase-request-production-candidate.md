# v20260820.3 生产候选说明

## 发布内容

- 已退回的采购申请新增“关闭”操作，需求提交者可结束不再继续处理的申请。
- 关闭前必须二次确认；关闭后申请进入终态，不再允许编辑、提交或继续审批。
- 系统管理员可协助关闭，其他账号不能越权操作；关闭动作写入现有流程记录。
