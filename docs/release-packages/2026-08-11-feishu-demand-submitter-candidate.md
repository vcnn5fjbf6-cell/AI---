# 2026-08-11 飞书审批卡片需求提交人生产候选清单

状态：候选。须由上线管理重新构建固定镜像、完成隔离批次测试并确认后发布生产。

业务功能提交：`d7efcd2264d977fc3cfc12d1081960542b0b7449`

关联问题：采购审批卡片只有申请标题、审批人和管理员抄送人，月度汇总采购无法直接看出各项需求最初由谁提交，容易把系统汇总触发人误认为需求人。

本批次包含：

- 普通采购审批卡片显示当前申请的原始需求提交人。
- 月度汇总采购按明细关联的源申请读取提交人；多人汇总时顶部显示姓名摘要，并逐项显示对应提交人。
- 替换商品确认卡片沿用同一来源，逐项标明原始需求提交人。
- 飞书审批卡片与系统版本升级为 `v20260811.1`。

本批次不包含：

- 不修改采购申请、供应商报价、审批节点或审批状态。
- 不新增数据库表、字段或增量脚本。
- 不改写已经发送的历史飞书卡片；旧卡片需要在卡片日志中重新发送后才能使用新版格式。

已完成验证：

- 后端完整测试 172 项通过，包含普通申请、多人月度汇总、历史数据回退和替换商品明细测试。
