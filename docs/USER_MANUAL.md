# 数据中心第三方运营综合管理系统使用手册

## 1. 系统定位

数据中心第三方运营综合管理系统，覆盖：

- 采购申请
- 审批流转
- 供应商协同
- EHS 工作台（测试环境）
- 审计留痕

## 2. 登录与权限

### 2.1 登录

- 访问前端地址：`http://<前端地址>/login`
- 输入账号、工号或中文姓名与密码登录。
- 如果中文姓名对应多个账号，点击“进入工作台”后先选择本人身份；弹窗会展示姓名、工号和所在部门，确认后再进入工作台。

默认种子账号（来自 `seed.sql`）已禁用固定初始口令。首次部署后请通过用户管理或数据库运维流程为测试账号设置一次性强密码，并要求登录后修改。

账号密码要求：

- 登录后可在右上角“账号 / 修改密码”修改本人密码；内部账号也可在“平台管理 / 我的权限”点击“修改密码”。
- 供应商账号点击“账号 / 修改密码”会直接弹出改密窗口，不需要进入“我的权限”页面。
- 密码每 90 天必须修改一次；到期后系统只允许调用改密接口，其他业务操作会在当前页面提示先修改密码。
- 新密码不能与当前密码一致，也不能与最近 6 次使用过的历史密码重复。
- 修改成功后当前登录会话会失效，需要重新登录。

### 2.2 权限控制

系统有两层权限：

- 路由权限：按角色控制页面访问
- 按钮权限：按 `perm_code` 控制按钮显示（`v-perm` 指令）

平台权限申请审批属于管理动作，只对管理员或具备 `platform_permission:manage` 权限的账号开放；普通账号即使能看到本人申请记录，也不能通过工作台接口审批权限申请。

最高管理员权限统一使用 `SUPER_ADMIN` 一个角色判断；历史 `ADMIN`、`SYS_ADMIN` 账号上线迁移后会自动归一到 `SUPER_ADMIN`，旧最高权限分组会停用。为兼容生产历史账号，系统管理员能力仍会识别 `SUPER_ADMIN`、`SYS_ADMIN`、`ADMIN` 三类旧有账号标识。

## 3. 页面说明

## 3.1 首页仪表盘

路径：`/dashboard`

功能：

- 显示采购申请总数、待审批数、供应商数、审批记录数
- 展示最新采购申请
- 快速进入“新建采购申请”

采购看板路径：`/procurement/dashboard`

- 页面通过采购 BI 接口读取真实采购、报价、审批和售后数据，展示需求金额、中标金额、采购数量、成交供应商和平均交期
- 当前可选数据源包括“采购明细表”“供应商报价明细表”“中标收货明细表”“售后明细表”“供应商报价汇总表”和“审批过程表”，字段在界面中均显示中文名称
- 支持商品采购、供应商表现、金额分布、组合表和采购明细小组件
- 供应商表现中展示每家供应商的报价单数、中标单数、中单率、成交金额和平均交期
- 商品采购中展示商品名称、规格型号、采购数量、中标数量、需求金额和中标金额
- 金额分布按机房简称和收货城市汇总，机房简称默认取完整部门路径最后一个 `-` 后的名称；采购明细展示已中标商品、供应商、城市、数量、金额和交期
- 组合表支持选择采购明细、报价明细、中标收货、售后明细、供应商表现、机房金额和收货城市等数据源，并按“按什么分组”和“统计什么数值”自由组合
- 组合表支持表格、条形图、饼图、环图和折线图展示；“选择组件”可直接新增饼图、条形图和折线图，图表模式下可独立调整图表维度、数值指标、展示数量和图例开关
- 每个组件都可以单独设置时间范围：点击“调整看板”后选中组件，在右侧基础配置里选择开始/结束日期；只影响当前组件及它的图表钻取明细，清空后当前组件恢复全量
- 柱状图和折线图可同时显示多个统计数值；点击某个图表数据项会打开对应分组的明细，并按当前点击的统计数值过滤掉 0 值记录。明细弹窗顶部可输入关键字筛选，也可在“选择显示列”中隐藏或恢复列
- 编辑模式采用画布加右侧配置面板，点击组件后会蓝框选中，并在右侧按基础配置、自定义配置和汇总算法配置标题、数据源、显示列、分组字段、统计数值、图表类型、主题色、数据标签、坐标轴和网格线
- 组件标题统一在右侧面板编辑，画布内只保留顶部拖拽点和选中后的快捷操作，避免误拖和编辑控件遮挡图表
- 复制组合表或图表后，每个组件可独立保存自己的字段组合、搜索条件、展示方式和图表配置
- 小组件可拖拽排序、隐藏显示、复制、编辑标题，并可在编辑模式下拖动右下角手柄自由调整宽度和高度，布局按当前账号保存；组合表和采购明细的表格内容超过组件高度时会在组件内部滚动，不会继续撑开页面
- 非编辑模式下点击柱状图、折线图、饼图或环形图的数据项，可打开对应分组的明细弹窗，查看最多 500 条明细数据
- 系统管理员可查看全量 BI 数据；供应商账号只展示本供应商相关记录；内部账号只按本人所在部门，以及审批策略/机房路由中明确授权的部门或机房范围展示，发起过或审批过整单不会额外放大看板统计范围
- 智能分析底座已预留中文字段字典、问答缓存和向量检索能力；当前页面仍以现有采购看板为主，后续接入智能体后会优先使用中文字段和当前账号权限范围回答数据问题

新建采购申请路径：`/procurement/requests/create`

- 打开新建页时系统会先分配并展示申请单号
- 编辑采购明细时，可在“采购原因”旁点击“AI优化”。系统会把优化表述追加到当前原因后，申请人确认后再保存明细；该操作不会自动保存或提交申请，也不会替代申请人核实内容
- 申请信息和采购明细填写完成后，可点击“AI预审”检查采购原因；预审结果按“必须补充、建议优化、链接核验”分级展示，可逐条采用或一键采用。采用结果只回填当前浏览器草稿，不会自动保存、提交申请或改变后续审批结论
- 对过于笼统的采购原因，采用后会补入“使用场景、现状问题、采购必要性”填写框架；必须补全其中的待填写内容后才能保存或提交。逐条采用后仅当前行显示“已采用”，其他待补充行仍可继续采用；手工修改申请内容后，原预审结果会标记为需要重新预审
- 普通采购单号格式为 `PTCG-100000` 起始递增，紧急采购单号格式为 `JJCG-100000` 起始递增
- 系统按需求池生成的全国/月度汇总工单使用独立单号 `HZCG-000000` 起始递增，后续由该汇总单再拆分到报价、订单和补充采购流程
- 如果网络卡顿导致重复提交，系统会按已分配单号识别为同一张采购单，避免生成多张重复审批

统一工作台路径：`/workbench`

- 统一请求队列只展示当前账号相关内容：待本人处理、本人已处理、本人发起、审批时明确抄送给本人，或本人被配置为部门助理后可见的本部门采购工单
- 系统管理员账号进入工作台时为全量视图，会分页加载全部采购申请和售后请求；普通账号仍按本人相关或部门助理授权范围过滤
- 统一请求队列不展示兼容用的单据类型字段；采购分类以采购明细中的“采购类型”为准
- 队列排序为待办优先、已办其次、本人发起/部门工单/抄送随后；计数为 0 的筛选页签默认隐藏
- “我的关注”在统一请求队列的页签中筛选，不再单独占用右侧区域；点击队列行前的小旗标可加入或取消关注
- 工作台底部采用三栏布局：左侧展示本周处理概览，中间展示审批进度分布，右侧展示公告栏
- 公告栏对内部账号展示启用公告；具备 `workbench_notice:manage` 权限的账号可点击“编辑”进入公告维护界面，新增、编辑、停用、置顶或删除公告
- 采购单只有仍处于待审批时才显示当前处理人姓名；没有明确处理人时才显示流程节点名称；已通过、部分通过、进入报价、需求池、订单或售后阶段后，当前节点显示为“完成”
- 工作台、审批弹窗和提交确认中的人员展示只显示姓名；工号仅用于登录、身份选择、用户管理和导入校验等身份识别场景
- 采购提交前的确认弹窗采用审批确认卡片样式，只展示申请单号和下一步审核人，提交节点、审核规则和说明性提示不再展示
- 点击单号可打开详情弹窗处理审批或查看流程状态
- 中标替换商品待办会并排展示原商品和替换商品，卡片顶部显示申请单号、原申请人、提交供应商、提交时间和剩余时限；规格或单价变化会单独标出。处理人只能为每项选择使用原商品报价或替换商品报价并提交，不能在该待办中直接修改供应商方案

EHS 工作台路径：`/ehs/dashboard`

- EHS 当前只在测试环境启用，生产环境默认关闭；账号必须开通 `EHS` 系统入口，供应商账号不显示 EHS 菜单。
- 一级菜单为“EHS工作台”，二级菜单包含总览、隐患管理、环境与危废、PPE与应急物资、事故事件、作业许可、智能助手和运行设置。
- 总览展示各台账真实记录数、处理中数量、预警数量、作业许可审批情况和当前风险队列。没有业务记录时显示 `0`，不会生成示例数据。

四类业务台账：

- 隐患管理：登记隐患描述、位置、风险等级、整改责任人、检查人、整改期限、整改措施和验收结论；状态依次为待整改、整改中、待验收、已闭环。
- 环境与危废：登记废物名称、代码、产生工序、库存、累计产生量、已转运量、处置单位和联单编号；状态为暂存中、待转运、已转运。
- PPE 与应急物资：登记物资名称、类型、规格、库存、最低库存、存放位置、有效期和更换日期；库存不足或即将到期会进入预警。
- 事故事件：登记事件概述、类别、等级、地点、发生时间、报告人、即时处置、原因分析和整改进展；状态为待处理、调查中、整改中、已结案。
- 每个台账均支持新增、编辑、删除、关键字和状态筛选、分页、Excel 模板下载、批量导入和整表导出。导入表的“名称”和“状态”为必填项。

作业许可：

1. 申请人在“作业许可”点击“新建总作业票”，填写申请信息、作业所属部门、作业地点、时间、内容、风险与控制措施、安全行为告知、关键设备步骤、角色签名和附件链接。
2. 选择需要的专项票。专项票包括动火、高处、受限空间、临时用电、吊装、动土。页面不再选择审批人；系统直接读取“平台管理 / 部门管理”中该作业部门已启用的审批链。
3. 保存后作业票为草稿，点击“提交”后，总票和所选专项票分别写入平台统一审批实例、审批待办和审批记录。节点顺序、节点候选人和“任一人通过/全部人员会签”规则与部门管理配置一致，当前审批人可在“待我审批”页签处理。
4. 总票和全部专项票都通过后，“确认开工”按钮才会出现。点击后总票和专项票同时进入作业中。
5. 受限空间专项票在执行期间可追加气体采样，记录时间、位置、氧气、LEL、CO、H₂S、记录人和签名。
6. 关单时先逐张关闭专项票，再关闭总票。关单必须填写正常完成、取消作业或异常结束，实际结束时间、签名和说明，可登记最多 6 个现场照片链接。
7. 只有申请人可以确认开工和关单。管理员可协助修改草稿或退回票，但不能代替申请人关单。
8. 每次提交、审批、全部票通过、可关总票和最终关单都会记录通知结果；飞书未启用或发送失败时不会回滚审批，结果可在 EHS 运行状态中查看。

外部作业入口（测试环境）：

- 外部申请地址为 `/ehs-public/apply`，供应商或施工人员无需平台账号即可填写申请。提交后页面生成本次申请的专属进度链接，请申请人保留该链接。
- 进度链接可查看总票和专项票状态；票据被退回后可修改并重新提交，批准后可确认开工、记录受限空间采样并按专项票优先的顺序关单。
- 审批人从飞书通知打开专属审批链接，无需再次登录平台即可通过或退回。链接只对应当前作业票和当前内部审批人，提交一次后立即失效，审批人和审批意见仍写入统一审批记录。
- 进度链接和审批链接都是访问凭证，不应转发到无关人员。链接无效、过期或已使用时，页面会拒绝继续访问。

智能助手与知识库：

- 智能助手可直接查询当前隐患、危废、物资、事故和作业许可统计，并在回答下方标明实时台账或知识文档来源。
- 可新增知识正文，或上传 `txt`、`md`、`csv`、`json` 文件，用于检索制度、标准和应急预案。
- 助手不会自动通过、退回或关闭作业票；所有状态变更仍由对应业务页面和统一审批任务完成。

我的权限路径：`/platform/access`

- 页面按“系统入口”展示采购管理、维保管理、EHS 工作台（测试环境）和平台管理的开通状态
- 未开通入口可直接选择系统并填写申请原因；页面不再要求用户选择旧的申请角色
- 审批通过后开通系统入口，具体角色和管理权限由管理员在用户管理、角色管理中维护
- 页面右上角提供“修改密码”，账号下拉菜单也提供同一入口，用于本人定期改密或处理密码到期提示

全员意见反馈入口：

- 登录后左上角品牌区下方显示“意见反馈”按钮，所有已登录账号都能提交。
- 反馈支持选择类型、填写标题和文字说明；文字说明和“相关链接”里的 `http/https` 地址会一并保存，方便管理员追溯页面、飞书、商品或外部资料链接。
- 支持上传最多 5 张图片，每张不超过 5MB；截图会作为附件保存到后台，普通用户提交后不能查看其他人的反馈。
- 管理员可在“平台管理 / 意见反馈”查看完整消息、链接、提交页面、图片附件和处理状态，并可更新处理说明。

系统更新入口：

- 系统管理员可在“平台管理 / 系统更新”查看当前正式版本和近期发布记录。
- 页面按“问题修复、功能更新、体验优化”分类展示，每条记录标明所属版本、上线日期和处理状态。
- 表单填写或导入格式错误会直接提示用户修正，不进入错误台账；已经修复的系统问题仍可在系统更新页面按版本追溯。

测试环境上线管理：

- 测试站的 `SUPER_ADMIN` 可在“平台管理 / 上线管理”直接查看安全上线工作台。
- 首次进入上线工作台仍需输入上线管理员账号；该账号独立于平台后台账号。
  - 页面内可按模块筛选并勾选可上线更新；候选区底部固定显示已选数量、当前不可创建原因和“创建批次并开始组合测试”按钮。
  - 创建批次后先进行组合测试，测试通过后才会显示生产发布确认操作。
- 如浏览器阻止内嵌登录或展示异常，可点击右上角“新窗口打开”进入同一安全控制面。

## 3.2 用户管理

路径：`/platform/users`

功能：

- 用户分页查询（账号、姓名、状态）；自有员工账号页签支持按工号、用户类型查询，供应商账号页签支持按关联供应商查询
- 账号列表按“自有员工账号 / 供应商账号”页签拆分，避免内部人员和供应商登录账号混在一起管理
- 新增用户
- 编辑用户
- 办理员工离职：员工列表点击“办理离职”，系统先列出该人员关联的长期审批配置和当前待办审批；管理员需为每个影响项逐一选择启用中的替换员工，全部交接成功后账号状态改为“离职”
- 离职账号不能登录，已有会话立即失效；角色和应用权限作为历史配置保留但不再生效。供应商账号不使用离职流程，仍通过“停用”控制
- 删除用户
- 角色分配
- 用户名自动同步工号，不再手工输入；工号为必填且全局唯一
- 供应商账号必须绑定供应商档案；手机号、邮箱、飞书 ID 和绑定部门属于可选字段，可在编辑时清空保存

- 流程图只展示真实处理过的节点和当前待处理节点，跳过或无人审批的节点不会显示
- 没有中标替换商品时，流程图不会显示“申请人替换商品确认”；只有供应商报价中被选中的明细标记了替换商品才会显示该节点
- 报价定标后如中标明细包含替换商品，会先派发“申请人替换商品确认”待办；申请人确认页只展示替换商品报价行，包含原商品、替换商品、供应商报价、联系电话、中标状态、交期和报价说明；申请人同意后后续审批金额和订单明细按替换商品执行，申请人不同意或 2 天未确认时按原商品和原报价继续，再进入经理报价审核
- 提交审批后系统会显示下一步审核节点、通过规则和候选处理人
- 楼长及后续节点可在审批明细中打开“单项驳回”并填写原因；未打开时明细仅展示原采购原因

- 审批处理弹窗会在意见说明上方展示流程状态和最近处理记录，按钮组统一显示为“审批意见”，便于提交前核对历史处理情况
- 加签会给指定人员追加当前节点待办，不改变原节点“任意一人通过/全部通过”的通过规则
- 全国月度需求汇总单由系统在月度触发日自动生成 `HZCG-*`，生成后直接进入供应商报价，不再派发经理/区域经理需求确认待办；管理员排障时可在报价和工作台中查看该汇总单。
- 管理员在工作台可看到全部采购工单；仍在审批中的全国月度需求汇总单会归入“待我处理”，已流转完成或进入报价的汇总单可在“全部”“我发起”或对应状态筛选中查看。
- 采购已办列表中，如果当前账号已经处理通过，但单据还在等待其他审批人确认，状态会显示为“待他人确认”；只有仍需当前账号处理的单据才显示为“待我处理/待审批”。
- 全国月度需求汇总单由系统自动触发，工作台列表和详情中的“发起人”统一显示为“系统管理员”，普通来源采购申请仍显示原申请人。
- 全国月度需求汇总标题中的“X张申请/Y项明细”表示来源采购申请单数量和汇总后的采购明细行数量；历史标题里的“X单/Y项”会自动按新口径展示。
- 全国月度需求汇总单只作为内部汇总和审批单使用，不会再次作为下次月度需求池发布的来源；月度发布只会汇总普通来源采购申请。
- 需求发起人在“本月需求”页面可在月度汇总前减少自己提交的需求池商品数量，或删除自己提交的需求池商品；数量只能调小，不能增加，删除后的商品不会进入后续月度汇总。
- 供应商报价比对后会重新发起报价复核：不超过 5000 元由 V4 经理终审，超过 5000 元继续 V5 区域经理；超过 100000 元只有在后台启用 V6 总监节点时才继续进入总监审核。
- 普通采购（PTCG）的楼长需求审核以每月集采自动发起日为截止，默认 20 日 23:59:59 前确认即可纳入当月；其它审批阶段和全国汇总单默认有 4 个工作日处理期限，系统管理员可在“采购规则”中调整“审批确认工作日”。超时后待办不会被系统自动退回或驳回，审批人仍可同意。超期同意后的普通采购会顺延到下月执行，已完成的审批不需要回需求池重新审批。系统管理员在“本月需求”页面点击“测试超时”只统计当前超期待办数量。

## 3.13 供应商报价

路径：`/procurement/quotes`

功能：

- 供应商对每条原商品报价必须选择“全新”或“二手”；选择二手时必须填写来源、使用年限、翻新或拆机情况。提出替换商品时，替换商品也执行相同规则
- 提交报价后，系统先按后台启用的资产目录匹配，再由 M3/MiniMax 异步复核商品语义和成色。模型不直接决定资产编码，返回编码必须存在于当前有效目录
- 命中资产目录的商品统一标记为“固定资产”，未命中目录的商品统一标记为“低值易耗”。二手商品单价达到 1000 元时会另行显示“需特殊审批”，不改变固定资产或低值易耗分类；M3 暂不可用、置信度不足或成色冲突时标记“待人工确认”
- M3 暂不可用不会阻止供应商提交报价，也不会自动修改报价或替换商品；系统保留供应商声明并在报价详情中提示人工确认
- 供应商账号查看被推送给自己的报价任务并提交逐项报价
- 普通采购需求池发布后会全国汇总为一张供应商报价大单；报价明细按行展示收货城市，供应商按城市把配送/运费摊入商品单价，不单独填写运费
- 批量导入报价必须使用当前报价单导出的模板；系统会校验行号、物料编码、商品名称和规格型号，多余行、重复行或明细不一致时整次拒绝导入。原商品或替换商品成色留空时默认按“全新”导入，填写“二手”时仍必须补充二手说明
- 系统生成的询价单会把有效电商地址转换为可点击的 Excel 超链接；历史明细中的无效地址显示“链接无效，请联系采购人”，供应商无需反复尝试失效地址
- 系统生成的询价单会把每条明细的交期天数预填为 7 天；供应商留空回传时也按 7 天导入，可按实际交货周期填写其他正整数，0 或负数仍会被拒绝
- 供应商手工逐项报价时，打开“替换商品”开关会自动展开该行替换方案，并把原商品与替换商品的规格、报价差额和比例放在同一区域对比；涨幅超过 13% 会标红。替换商品名称、规格型号、商品链接、单价和替换原因必填，缺项或链接无效时页面会自动展开、定位并标红对应字段，提交前还会再次确认替换方案。鑫方盛账号可在替换商品链接处直接填写内部商品编号，例如 `23629538` 会自动转换为对应的鑫方盛 VIP 商品页；其他供应商的纯数字不会套用该规则
- 批量导入继续使用当前报价单导出的模板；模板会标出替换时必填列，导入与手工填写执行同一套完整性和商品链接校验。提交保存时系统保留供应商填写的原商品单价，不修改替换商品报价；进入报价复核前，如该行提出替换商品，原商品有效比价单价按其他有效供应商原商品第二高单价加 1 元调整，只有一家可比供应商时按该供应商单价加 1 元，无可比供应商时保持原价。其他替换报价不参与基准价计算，系统同步重算行金额和报价总额；供应商原始提交单价独立留存供审计。只有中标后才会进入现有“申请人替换商品确认”节点
- 供应商可以放弃全部报价明细并提交；该记录只作为放弃报价留痕，不计入 3 家有效报价，也不会参与中标
- 被楼长或经理单项驳回的明细不会展示给供应商报价，也不会进入有效报价统计
- 内部需求人满足 3 家报价后可手动触发报价审核；未产生中标结果前，除系统管理员外，内部账号只能看到报价供应商数量，不能查看供应商名称、报价金额、交期、报价明细或导出报价审核表
- 低额紧急采购可在价格受控时免三方比价：楼长通过后，如果有效金额低于后台阈值，系统优先指派历史单项中标次数最多的可用供应商；无历史中标记录时兜底指派当前可用供应商。定向供应商报价不超过阈值 130%（默认阈值 1000 元时上限 1300 元）时可提交报价审核；超过上限会转回正常三方比价
- 报价截止日期前已满足 3 家供应商提交报价时，系统自动开启 3 小时倒计时；倒计时结束后按系统自动中标策略进入报价审核
- 列表和详情中的“自动比价”字段会展示当前是否仍按报价截止时间等待、是否处于 3 小时实时倒计时、是否低额紧急定向免三方比价，或是否已进入报价审核；低额定向单会额外显示指派供应商，若定向报价超过上限则恢复为三方比价
- 报价默认开放 7 个自然日，具体天数读取“采购规则”中的 `quote_open_days`；报价列表、需求清单和逐项报价弹窗都会展示最晚报价截止时间
- 供应商超过报价截止时间未提交报价时按放弃报价处理，页面会禁用提交报价，后端也会拒绝过期报价
- 报价期满后，系统会排除未报价供应商并按已有有效报价继续自动比价；如果没有任何有效报价，申请会保留在报价中等待管理员处理
- 系统管理员可在报价列表点击“延期”，为报价中的申请增加 1-60 个自然日；延期后供应商可在新的截止时间前提交或更新报价
- 供应商中标后，中标商品明细会显示送达地址；地址来自部门/机房基础数据，导出的中标清单也会包含该地址
- 全国汇总单进入报价复核后，会按来源需求拆分给对应经理确认；经理只看到自己负责来源需求的明细，所有经理确认通过后再继续后续流程
- 系统选出中标商品后，仅按中标商品比较中标单价与参考单价；高于参考价 13% 的商品进入楼长超价复核，楼长须在 24 小时内通过或单项驳回。复核页和飞书卡片会展示提交者、来源工单、中标单位、差额和比例；不支持整单退回，驳回商品停止采购，其余商品继续流转。通过商品必须填写具体的价格合理原因
- 正式提交时的 AI 审核意见只读取每条明细的“采购原因”，用于判断具体场景和采购必要性是否说明清楚；标题、金额、紧急程度、商品、规格、数量、单价和链接不参与 AI 审核。上述字段仍由系统原有硬校验和审批流程处理
- 供应商工作台和报价列表会展示中标状态：已确认显示“中标”，未确认显示“中标待确认”
- 中标待确认期限默认为 4 个工作日，周末和后台设置的节假日不计入；逾期未确认会自动视为放弃，并按原中标规则递补下一名供应商
- 中标待确认时，供应商可点击“确认中标”或“放弃中标”；主动放弃会立即递补下一名供应商，报价详情会在对应供应商区块标注“放弃中标”并展示放弃原因
- 供应商确认中标后，系统页面会自动下载包含中标明细和送达地址的 Excel 清单；飞书中标确认卡片会自动把清单文件发送到当前会话，也可在报价列表、报价详情或飞书已处理卡片点击“下载中标清单”重试
- 半年内累计 3 次放弃中标（含主动放弃和逾期自动放弃）后，供应商会被暂停 3 个月投标；暂停期间不能提交新报价，也不会参与自动定标或递补

## 3.14 平台集成与采购规则设置

路径：`/platform/integration-settings`、`/platform/procurement-rule-settings`

功能：

- 在“平台集成设置 / 邮件服务器”区域配置企业邮箱 SMTP 服务器、端口、发件邮箱、用户名、密码以及 SSL/STARTTLS
- 开启“启用中标邮件”后，供应商中标会向供应商主数据中的联系邮箱发送确认通知
- 在“采购规则设置 / 采购规则”区域维护中标确认工作日数、节假日和调休工作日，影响自动放弃和递补计算
- 在“采购规则设置 / 采购规则”区域可调整普通采购允许提交的开始日和截止日；用户不在日期窗口内提交时，系统会提示当前日期、允许提交日期和下一次可提交日期
- 在“采购规则设置 / 采购规则”区域可启停“低额紧急采购定向报价”，并调整触发阈值，默认低于 1000 元启用；默认配置下定向报价金额上限为 1300 元，超过后不再免三方比价
- 在“采购规则设置 / 采购规则”区域可调整报价开放天数 `quote_open_days`，默认 7 个自然日；单张报价申请需要临时延长时，由管理员在供应商报价列表执行“延期”

## 3.15 我的订单与售后

路径：`/procurement/orders`

功能：

- 查看本人成功下单或与本人供应商账号相关的中标订单；供应商未确认的中标单会显示为“待供应商确认”。
- 订单列表按集采/采购单展示，`HZCG-*` 集采单会汇总当前账号相关的中标商品、供应商、金额、待收货数量和售后状态；列表顶部可按“全部 / 集采订单 / 紧急采购 / 普通订单”标签切换，每个标签独立分页。
- 点击集采单后按“机房 → 中标供应商 → 订单归档”逐级查看。机房层展示申请数、商品数、中标供应商数、金额和交付进度；供应商层展示中标商品摘要、金额、订单交付以及发票归档情况。
- 供应商订单归档分为“订单、发票、签收单”三个页签。订单页可查看商品、金额和交付状态，并按权限确认收货、申请售后或进入工作台；发票与签收单页复用订单资料的上传、查看、确认、退回和历史版本能力，并分别提供“批量上传发票”和“批量上传签收单”。批量窗口要求在每笔订单行单独选择文件，提交时仍逐单校验供应商归属和账号权限。
- 点击订单号打开协同详情，可查看当前责任方，以及“确认中标 → 供应商确认 → 订单生成 → 配送中 → 已签收 → 发票/验收单提交 → 已提交付款”的关键节点。签收后需要发票和验收单均有效提交；两类资料均确认后显示已提交付款。下一步、最新动态以及订单资料、售后和来源申请会同步更新，现有导出、资料、确认收货和售后按钮仍按原权限显示。
- 供应商归档支持导出 PDF，导出范围只包含当前集采单、当前机房和当前供应商，并保留完整物品详情、比价信息和审批流程。紧急采购和普通订单继续使用原明细表与单笔订单导出。
- 申请人、采购员可查看自己相关订单；来源部门助理可查看其已授权部门的订单；供应商账号只能查看本供应商中标订单。
- 中标供应商确认订单后，可在“已售管理”的订单明细打开“订单资料”，分别上传发票和签收单。上传仅允许最高管理员、本订单供应商，以及具备 `procurement_order:supplier-manage-all` 的跨供应商最高监督账号；来源部门助理、普通采购人员、楼长和其他内部账号均不能上传。历史记录继续保留上传人及身份。
- 发票和送货单分别维护版本及状态，上传一种资料不会覆盖另一种。每次选择 1～5 个 PDF、OFD、XML、JPG、JPEG 或 PNG 文件，单个文件不超过 20MB；重新提交会生成新版本并保留历史文件。每类资料最多保留 50 个版本，单个订单累计附件不超过 500MB。
- 资料状态包括“待确认、已确认（发票显示已收票）、已退回、已被新版本替代”。订单采购人、来源部门助理和来源需求单当前 V3 楼长可以按原权限查看、下载并确认或退回最新版本，但不能上传；退回时必须填写原因。最高管理员可查看、上传和处理，其他账号即使知道订单号或附件编号也不能越权操作。
- 本订单供应商或跨供应商最高监督账号上传发票或签收单后，系统向来源部门助理发送飞书卡片，卡片包含订单号、申请单号、供应商、资料类型、版本、上传人和文件数量。最高管理员上传时不触发该供应商侧通知。
- 订单资料审核权限本身不扩大订单操作范围：来源部门助理按部门授权可导出采购操作订单、确认收货和处理售后；仅因 V3 楼长身份看到资料的人员仍不能执行这些订单动作。
- 供应商确认中标后订单进入“待收货”，由申请人、采购员或来源部门助理在确认实际到货后手动收货；系统不再自动收货。
- 收货后才可发起售后申请：默认支持收货后 7 天无理由退货和 14 天退换货，具体是否启用和天数由“采购规则设置”维护。
- 售后申请填写售后类型、原因和数量；14 天退换货可补充新商品名称、规格、编码和更换说明。
- 售后申请提交前会显示“下一步：供应商售后审核 / 处理人”，处理人为当前订单的中标供应商；确认提交后进入该供应商工作台“待我处理”队列，取消确认不会提交。
- 售后处理统一在“工作台”完成：供应商先给出售后方案，方案可包含退换、维修、补发或更换商品；更换商品时需填写方案单价，且方案单价高于现价时最多只能增加 400 元。
- 供应商给出方案后，售后进入需求提交者、采购人和来源部门助理的“方案待确认”待办；任一有权人员同意后售后生效，不同意则退回供应商重新给方案，当前不生成服务失单记录。
- 同一订单明细已有待供应商方案、方案待确认或已通过售后时，不再显示“申请售后”；如果售后被供应商驳回，可在售后窗口未过期时重新提交。
- 退货类售后审核通过后，采购申请详情中的对应商品状态显示为“退货”，申请总金额会扣减该商品金额；采购看板的供应商表现会统计各供应商退货率、换货率和中单率。

供应商入口：

- 路径：`/procurement/sold-orders`
- 普通供应商账号在“已售管理”中查看本供应商中标售出的商品、订单金额、买方收货状态、送达地址和售后状态；同一供应商主档下绑定的多个账号共享查看本公司数据。具备 `procurement_order:supplier-manage-all` 的最高监督账号显示“全供应商管理”，可跨供应商查询已售数据。
- 普通供应商只能为本供应商已确认中标的订单上传或重新上传发票、送货单；其他供应商即使知道订单号或附件编号也不能查看、下载或修改。最高监督账号可代为上传订单资料、导出归档并处理供应商侧售后，但不能执行买方收货、采购审批、系统管理或修改原始报价。
- 售后待给方案的商品会显示“去工作台处理”，供应商需在工作台详情中填写方案或驳回售后；方案提交后等待需求方确认。

## 4. 典型业务流程

1. 采购员创建采购申请并保存草稿  
2. 采购员提交审批  
3. 经理/区域经理在“审批操作页”或“工作台”执行通过/退回/暂存/终止
4. 在“采购申请详情”查看审批轨迹  

## 5. 常见问题

### Q1: 登录后看不到菜单？

检查用户是否分配角色，角色是否启用。

### Q2: 按钮不显示？

检查角色是否分配对应 `perm_code`，以及权限状态是否启用。

### Q3: 提交审批后状态未推进？

当前版本审批操作写入 `approval_record`，申请状态自动推进逻辑仍建议在后端补充“审批动作专用接口”。
