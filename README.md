## 快速启动

开发者请先按[开发者指南的快速上手](docs/DEVELOPMENT_GUIDE.md#先从这里开始)准备独立开发库和本地环境。

> `backend-springboot/sql/schema.sql` 会删除已有表，只能用于可丢弃的全新本地库，禁止对生产库、共享库或已有数据的库执行。

1. 按开发者指南初始化独立的 MySQL 8 开发库。
2. 启动后端：进入 `backend-springboot` 执行 `mvn spring-boot:run`。
3. 启动前端：进入 `frontend-vue` 执行 `npm ci`，再执行 `npm run dev`。
4. 访问 `http://localhost:5173`；本地前端会把 `/api` 代理到 `http://localhost:8080`。
